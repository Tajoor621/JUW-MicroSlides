# JUW MicroSlides

Premium **Microbiology lecture slide generator** for university teaching.

**Brand:** Jinnah University for Women seal · **Slides by Noor** on every slide

## Best on laptop (with internet)

- Open-source media per research slide (Wikimedia Commons, Openverse, Wikipedia)
- Unique image or scientific diagram on each slide (no repeats)
- Camera / gallery upload for your own lab photos
- Themes + layouts for professional lecture decks
- Export **PPTX** (editable) and **PDF**

## Open media engines

1. Wikimedia Commons API  
2. Openverse (Creative Commons)  
3. Wikipedia REST  
4. Built-in unique vector diagrams (fallback)  
5. User uploads (camera / files)

## Deploy

GitHub Pages from repo root. Live example: `https://Tajoor621.github.io/JUW-MicroSlides/`
