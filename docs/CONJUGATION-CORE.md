# Conjugation teaching core — V6.2.1

The standard lecture path recognises a deliberately narrow set of general conjugation topic names. It uses an editorially composed, source-linked F-type teaching core instead of treating unrelated article paragraphs as a complete introductory lecture. Specialised organism requests, supplied instructor material, AI mode and other topics retain their research/writing paths.

The core has 14 distinct content lessons. With the title, objectives and two optional assessment slides it produces the 18-slide re-audit deck. Smaller decks select a subset without duplication. Larger decks still require additional research and fail explicitly if it is insufficient. A successful export is not scientific qualification.

Each lesson has a definition, mechanism, misconception, takeaway, concise bullets, presenter notes and an editable four-stage schematic. These schematics are original conceptual diagrams, not primary-study figures. No discovered media is attached automatically. The questions test transfer-origin function, recipient establishment and helper compatibility, with source-linked explanations in instructor notes.

All claims start unreviewed. Bibliographic identity inspection is separate from human claim verification. Thorough mode attempts live publication-notice checks for the core references and reports unavailable/cached checks; it never claims these checks establish scientific correctness. Metadata availability does not block editable export. There is no Review menu or review gate.
