## Technical architecture

Tauri 2 owns the Windows lifecycle, system dialogs and filesystem boundaries. React/TypeScript remains the shared editor. SQLite uses WAL and FULL synchronous writes; workspace changes and recovery snapshots commit together. Move growing projects from JSON state rows into migrated relational projects/slides/claims/references/assets/jobs tables, preserving project import compatibility. Keep credentials in the OS credential vault if remote providers are later introduced; none are required for the current local-model path.

The generation pipeline should persist a request fingerprint, retrieve and rank licensed evidence, assign a distinct teaching purpose to each of N outline slots, bind candidate claims to passages, draft in bounded batches, then validate count, topic coverage, conceptual uniqueness, citations and layout before atomically committing a new deck. Retry only failed slots. Never fill an evidence gap with generic pages or repeated statements. An impossible or insufficiently supported request must preserve previous work and explain what additional evidence is needed; an unconditional universal-content guarantee would conflict with scientific integrity.

A single slide scene remains the geometry contract for preview, audience and export. Add native PowerPoint render comparisons to the existing browser/XML checks. Keep images in a separately managed collection until explicitly attached; embed only legally usable assets with captions, source links, attribution and licence records. The .juwslides ZIP is the interchange boundary, with a schema manifest, embedded assets, hashes and expansion limits.

## Three lecturer journeys

1. **New lecture:** enter an unrestricted topic, level and integer count; optionally supply sources; inspect the N-slot teaching outline and evidence coverage; generate with visible progress/cancel; validate all slots; save a new draft only when exactly N unique substantive slides pass. A one-slide request combines topic introduction and substantive teaching content. Download required corpus/model resources before offline work.
2. **Edit and review:** select a slide; change text or notes with automatic revisions; inspect each claim's exact source passage and access limitations; record explicit review. Audit the whole deck for unsupported claims and overlap. Compare a regeneration proposal before apply; preserve locked slides and previous revisions. Expand in notes or rebalance within N slots, rather than quietly adding slides.
3. **Teach/export:** resolve critical review/layout findings; inspect the final slide count and media licences; save a portable project plus reviewed editable PPTX. Pick the audience monitor; keep current/next slides, notes and timing on the private console. Draft exports remain visibly labelled. Reopen the project after a forced restart without losing the last acknowledged save.

## Measures required for a 10/10 release

| Measure                   | Target and measurement                                                                                                                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Count fulfilment          | 100% of successful jobs deliver exactly N; zero partial-success saves. Publish completion rate separately, including failures, on ≥200 independently chosen microbiology/clinical topics and counts 1–50.                   |
| Substantive uniqueness    | Zero adjudicated redundant slides in the acceptance corpus. Report semantic detector precision/recall separately; a passing lexical screen is insufficient.                                                                 |
| Evidence traceability     | 100% factual claims source-linked or explicitly justified as foundational knowledge; no fabricated identifiers; all restricted evidence access disclosed; clinical guidance checked against current authoritative guidance. |
| Source quality            | 100% sources classified by type/access/publication status; clinical recommendations trace to applicable authoritative guidance; material corrections/retractions surfaced.                                                  |
| Export fidelity           | Zero clipping/overlap, consistent typography and geometry thresholds above across supported PowerPoint versions; text remains editable.                                                                                     |
| Time to professional deck | P95 <5 minutes on declared Windows hardware/corpus/model/network configuration, including validation. Record scientific-review time separately; never hide it in the timing denominator.                                    |
| Offline resilience        | 100% packaged dependency checks pass; downloaded-corpus workflows, editing, project roundtrip, presentation and export pass with network disabled; recovery retains every acknowledged save in fault tests.                 |
| Lecturer satisfaction     | ≥4.7/5 from at least 20 lecturers across microbiology subdisciplines; ≥95% complete generation, evidence correction and presentation tasks without assistance.                                                              |

No measured result should be replaced by a product promise. The qualification file records present implementation limits.
